# Parcial Apis

## Integrantes
- Heisser
- Ramiro

## Descripción
Aplicación en Python que consume la API de [Rest Countries](https://restcountries.com) para buscar países por las iniciales de los nombres de cada integrante. Usa programación orientada a objetos con las clases `Country` y `CountryAPI`.
